# 首次项目名确认候选 v3

本轮 6 会话/14 轮定向检查完成，已启用于原型新会话。完整证据及未解决项见 [启用记录](../../docs/voice-rules-update-2026-10-25.md)，不等于全量验收通过。

在冻结 v2 的通用规则之前增加一条有限范围规则：首次接收用户项目名时，确认准确名称；用户已明确确认/纠正后不再追问。普通聊天、未给名称的任务、助手自己的名字不触发。没有硬编码项目名或修改转写文字。

原因：v2 的“发现歧义再问”在两次名称案例里均未主动确认，但后续明确纠正有效。因此采用可观察的首次项目名确认行为，不要求模型先准确判断自己的识别是否可靠。

```sh
npm run voice:eval -- voice-v3
```

定向检查英文普通聊天、首次名称确认与纠正、能力边界，每类两次，共 6 会话、14 轮。未重复 v2 所有场景，未测真人打断与自然度。原 v2 报告（包括超时和未确认）保留，不能用本轮结果覆盖此前失败。

单案例诊断可使用 `npm run voice:eval -- voice-v3 name-clarification`，只运行该案例一次并产生用量。合成异常记录安全的事件计数；对话异常保留已采集的文字和历史，不保存原始音频。
