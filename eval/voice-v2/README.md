# 对话规则候选 v2（2026-10-25）

本版保留为候选历史，首次名称确认未通过，后续 v3 已定向修订并启用。见 [结果与故障记录](../../docs/voice-rules-update-2026-10-25.md)。

本目录独立于 `voice-v1`，不覆盖旧基线。`baseline.json` 固定候选规则、模型、音色；规则源码位于 `prototypes/voice/prompt-v2.mjs`。这是 P1 行为提示，不是正式模式状态机或已接入的工具权限系统。

变化：回答语言与教学意图分开；不虚构身体生活经历；明确当前没有日历/提醒/长期记忆/搜索工具；默认简短口语；关键名称疑似错断句时自然确认，用户纠正后使用新信息。没有写入测试题的标准答案，也没有特定项目名替换。

```sh
npm run voice:eval -- voice-v2
```

8 类案例各 2 次，16 个独立会话共 36 轮；18 条不同问题先合成并仅在内存缓存，同一问题复用相同声音。输入合成使用原 `voice-v1` 固定规则，实际对话使用本目录候选，防止输入生成随候选变化。报告记录两种提示摘要、案例摘要、转写、回复、服务端历史和 usage，不保存音频。

历史对照不是严格同音频 A/B：旧音频按约定未保存，重新生成的语速/韵律可能不同。评分区分核心目标、转写影响、表达缺陷和服务故障；程序 `unreviewed` 状态不得直接视为通过。短回答不通过字符截断实现，不以损失事实准确性换取简短。

首轮在合成第 9 条输入时超时，尚未执行对话案例。旧合成基线单条诊断成功后，保留失败报告并受控重跑一次；未开启自动重试。超时原因未确认，后续合成异常记录事件计数、已收到音频字节数与服务 log ID，不记录音频内容或密钥。
