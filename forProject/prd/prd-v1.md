# 综述
Jarvis是一款小型的对话机器人，作为一个实体存在，可以与人对话，可以回答人的问题，我会将它放在我做桌面，与我聊天对话；可以实现简单动作，机器人的底座不动，但是脖子处有旋转机构，可以随着说话转动关节，实现类似摇头、点头的功能；

# 硬件需求
+ 有小型的显示屏，显示屏中有眼睛的可爱拟人图案，可以随着时间变化、随着对话内容调整图案；例如长时间没人陪他聊天，可以显示为眼睛睁不开有困意的图案；聊天聊到开心的程度，显示为眼睛眯眯笑的图案；具体样式可以参考电影《机器人总动员》中瓦里的样子；
+ 脖子处有旋转关节，在与人聊天的过程中，根据聊天内容，旋转关节，以实现拟人话动作；例如认可和赞扬我的问题，可以点头；反对我的提议，可以摇头；
+ 具备语音识别和外放声音的硬件模块，可以实现自主与人交流；
+ 硬件系统的设备，我建议选择可以搭载ubantu系统的硬件设备，并且在选材上要具备可扩展性，例如如果后续外接视觉模块的需求，需要可以搭载视觉传感器、独立小型显卡设备等；

# 软件系统需求
+ 机器人的聊天对话能力，要基于大模型实现，大模型能力可以是联网实现，连接api key实现，而不是本地部署大模型，要具备一定联网搜索能力；本地要有自己的记忆库或则知识库，可以沉淀每一次对话内容的精华；
