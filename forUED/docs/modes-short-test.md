下面是保留的原四模式步骤，待继续模式体验时使用。

预计 3–5 分钟。本次只体验新模式，不重复唤醒或红茶记忆测试；英语总结已在 11-01 后续接入，单独短测见顶部链接。

1. 打开或刷新 [隔离测试页](http://127.0.0.1:8767/)，点“开始聊天”。留意“当前模式”一行。保持页面前台。
2. 说“陪我练英语”，随后说“Let's talk about breakfast.”。随便回答一两句，再说“我不明白你刚才的问题，用中文解释一下”。应先中文解释，模式仍是英语练习；不应纠正大小写和标点。
3. 说“不练英语，只是聊天”。应回日常并中文确认；再自由聊一句，感受是否还在强行教学。
4. 说“我正在写代码，什么是线程？”。应进入工作，先简短告知，再回答问题。若刚切完模式后一轮没切，继续问“Java 的接口和抽象类有什么区别”，观察下一轮。
5. 说“不要切换”。应回到日常，显示“本次不自动切换”。再说“我正在看英超比赛”，应继续保持日常。然后说“进入陪伴模式”，手动切换仍应成功。
6. 点“结束聊天”，再点“开始聊天”。应仍是陪伴，且不再显示自动切换锁定。最后结束会话，确认“麦克风关闭”。

有问题时只需记下大约时间、你说的话和异常表现，不用为了通过反复尝试。技术答案也可能有误，模式标签正确不代表内容已经通过验收。

完成后告诉我“测试结束”。我会先核对日志，再问切换是否打断聊天、中文求助是否到位、英语话题难度，以及其他需要你判断的听感。
