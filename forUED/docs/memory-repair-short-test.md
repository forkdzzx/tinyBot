2026-10-29，约三分钟。只测本轮改动与等待现象，不重复唤醒测试。无需重新配置云服务或添加硬件。

1. 刷新[测试页面](http://127.0.0.1:8766/)，点击“开始聊天”，等“可以直接讲话”。
2. 说“我想说一下，请你记住，我喜欢喝红茶。”这是你已确认的真实偏好，可以重复；也可换成另一条真实偏好。听它是否正常确认。是否真正落盘由我看日志核查。
3. 说“我想说中文了”，接着问一个简单问题。此要求应只影响当前交流；是否误存为长期档案由我核查，不需要你查看文件。
4. 说“我又有点不想聊天了，先结束吧”。先不要点结束按钮，观察是否自动显示“麦克风关闭”，并且“开始聊天”按钮可再次使用。若未关闭，点“结束聊天”即可，不必反复试读。
5. 再次点击开始，问“我喜欢喝什么茶？”；然后说“用英文聊两句”，按自己的习惯问一两个简单英文问题（如 `What can I do this weekend?`），正常停顿即可。若再次说完迟迟没有回应，记下大致时间和问题；等约 5 秒仍没答就正常追问，不必一直等待或强行改变发音。
6. 说“OK，可以结束”，再次观察是否自动关闭。若未关闭，手动结束即可。

完成后在当前对话说 **“测试结束”**。我会先核对即时保存、提炼结果、结束原因和时序，再问你必要的体验问题。无需现在逐项回答，也不用自己读日志。
