## 启动

在项目根目录执行 `npm run voice`，打开 http://127.0.0.1:8766 。Node 需 22 或以上；首次安装依赖运行 `npm ci --ignore-scripts`。按 Ctrl+C 停止服务。

凭证读取 `runtime/volcengine.env` 的 `VOLCENGINE_SPEECH_API_KEY`。默认使用官方示例音色 `zh_female_vv_jupiter_bigtts`；可通过同文件的 `VOLCENGINE_SPEECH_VOICE` 指定已获服务支持的音色。修改配置后重启服务。不要把凭证填进页面或聊天。

## 先试这四件事

1. 点击“测试一句问候”：不打开麦克风，确认扬声器能听到声音。程序播完会自动结束本次会话。
2. 点击“开始语音”，允许浏览器与 macOS 的麦克风权限。出现“已连接 · 正在收音”后直接问：“请简单解释 Java 的接口和抽象类有什么区别。”此阶段不需要唤醒词。
3. 连续聊几轮，再说：“陪我练英语，我是初学者，一次问一个简单问题。”观察识别字幕、回应速度和能否聊下去；这只是对话指令，尚未实现正式 Skill 模式。
4. 它说话时插话“停一下，换个话题”，观察是否停音并回应新内容。也可点击“打断播报”检查手动清空；手动成功不等于声学打断合格。

首次可使用耳机排除外放回声，随后必须补测 Mac 外放。默认依赖云端识别开始事件清空播放；实验性音量打断默认关闭，外放时可能被机器人自己的声音误触发。请反馈“不停音、抢话、误识别、答非所问”等具体体验和大致时间，我可以对应本地日志定位。

点击“结束”关闭收音。切到其他页面或把页面放到后台也会结束。连续验证最多 10 分钟，结束后稍等约 3 秒再开始。这里的开发限制不代表最终机器人行为。

## 本轮已经验证什么

- API 鉴权、创建会话、返回语音和关闭确认通过。
- 固定中文问题的合成音频回环得到识别文字、回答文字及音频，未使用真人声音。
- 通过本机代理真实发送取消事件，收到取消确认后再次请求问候，成功获得新音频并正常结束。
- 浏览器不启用麦克风的问候测试显示完成；9 项自动化逻辑测试通过。

仍需真人验证：麦克风权限与输入、外放回声、中文和英文连续对话、声学打断、主观听感及实际响应延迟。页面显示的“识别结束事件至首音频排程”不是 PRD 的用户实际说完至听到回答的端到端延迟。

## 数据与边界

密钥只由本机 Node 服务读取并发送至官方语音端点。浏览器与代理只监听 `127.0.0.1:8766`，仅支持一个前台会话。按下开始后，本轮麦克风音频会发送给豆包；程序不将音频写入磁盘。文字与事件日志在 `runtime/voice/`，文件权限为 600；这仍是开发诊断格式，尚不是正式历史/记忆系统。

本轮尚未实现本地唤醒、两分钟会话结束、主动搭话、勿扰、长期记忆、搜索、模式调度、真实动作和物理开关机。不要用这个页面判断整个 PRD 已完成。

## 排查

- 页面打不开：确认 `npm run voice` 仍运行，地址用 `127.0.0.1`，不要改为 `localhost`。
- 麦克风权限拒绝：在浏览器站点权限与 macOS 隐私设置中允许麦克风，然后重新开始；内置浏览器若不支持，请在 Chrome 打开相同地址。
- `NotFoundError`：浏览器未找到可用输入设备。此次已通过系统音频枚举确认只有输出设备、没有输入设备。需先连接可用麦克风或带麦耳机，在 macOS 声音设置中确认输入，再用浏览器试聊；更换浏览器本身不能补上缺失的输入设备。
- HTTP 401/403：核对本地凭证及对应服务权益；不要把完整 Key 贴进日志或截图。
- 没有声音：检查系统输出设备和音量，先运行问候测试区分输入、模型、播放问题。
- 断网或超时：本轮会停止并关闭收音，网络恢复后点击开始重连；自动恢复尚未实现。

## 口语表达与语言跟随定向复测

新会话已调整为口语短答，并明确英语练习中优先用中文接住中文插话。重新开始会话后只需体验两项：

1. 问一个日常或技术问题，听回答是否仍像读说明书，是否给你自然接话的空间。
2. 说“陪我练英语，问我一个关于早餐的简单问题”；它用英文提问时插话“等一下，我没听懂，你用中文解释一下”；听它是否先用中文解释。随后说“明白了，我们继续用英语练习”，检查能否回到英语。

这不是已实现完整 Skill 的声明。提示词调整不保证模型每次都遵循，真人插话和听感仍需复测；完成后用户说“测试结束”，再询问结果，不必重复整套七步测试。

追加普通英文交流检查：新会话直接问“What's your name?”，应自然回答名字，不擅自进入教学，不纠正语音转写的大小写或问号。进入英语练习后，正确句子也不应被硬凑出纠错。此项来自用户试聊反馈，不视为上一轮定向测试已经完成。
