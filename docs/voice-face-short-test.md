# Mac 语音与眼神短测

约 1～2 分钟。用平时的麦克风与扬声器，在一轮真实对话里看眼神、听插话。页面使用隔离的测试记忆，调用已配置的豆包语音服务，默认只保留文字和诊断事件。[打开本机测试页](http://127.0.0.1:8767/)

1. 打开或刷新页面，保持在前台。点击 **开始聊天**，首次使用时允许麦克风。看到「可以直接讲话」后说 **“给我介绍一下太阳系的八颗行星，每颗用一句话。”**
2. 听到它开始介绍第一颗行星时，自然插话 **“换个问题，一加一等于几？只说答案。”** 留意旧声音何时停、眼睛是否切回倾听、脸上的旧字幕有没有清掉，以及它最终回答了什么。脸下方的文字记录可用于核对识别。若一直不停，可以点一次 **打断播报**；记住用过按钮即可。
3. 听完新答后点 **结束聊天**。回到对话里告诉我 **“测试结束”**。若有异常，附上大致时间或当时说的话即可。

本轮直接使用 Mac 的浏览器录放音。设备协议和模拟回声的自动测试另有记录，K151 到手后再做机身的 20、50 厘米实测。[联调证据](k151-mac-preflight.md)

需要重新启动页面时，在项目根目录执行 `npm run voice:memory-test`，等终端显示 8767 地址后刷新。每次重启服务会创建新的隔离目录。
