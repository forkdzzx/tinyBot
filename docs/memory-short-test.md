# 跨会话记忆短测

**2026-10-29 本轮已完成，日志与体验反馈已整理，见[反馈记录](memory-feedback-2026-10-29.md)。无需重复本流程；修复后的定向步骤见[三分钟短测](memory-repair-short-test.md)。以下保留原流程。**

目标：检查你自然说话时能否正确保存、结束后再次引用，约三分钟。使用现有 Mac 与麦克风，无需喊唤醒词或重新配置凭证。

1. 刷新 [本地页面](http://127.0.0.1:8766/)，点击“开始聊天”。
2. 说一条**真实偏好**，以“请记住”开头。例如“请记住，我喜欢喝……”，填你自己的内容。听它是否简短确认。
3. 再普通聊一条**真实爱好或近况**，例如“我周末喜欢……”。这次不说“记住”，观察是否自然接话、有没有反复要求确认。
4. 点击“结束聊天”，等约 15 秒让后台整理；再点击“开始聊天”。
5. 问“我喜欢喝什么？周末喜欢做什么？”按你刚才使用的话题调整问题，**不要在问题里提前告诉它答案**。观察两条信息是否正确。
6. 再问一个无关的普通问题，例如“简单解释一下 Java 接口”，观察它是否正常回答，而不是硬提你的偏好。结束聊天。

完成后在这里告诉我 **“测试结束”** 即可。我会先核对日志，再问你体验问题。若出现异常，顺手记下大致时间和一句现象，不需要反复重测。

这次使用真实资料，以免测试内容进入日常记忆后造成误解。暂时不专门测新旧信息冲突、项目名或五条记忆验收；这些还有待完成的处理流程。后台若暂时失败会保留任务，不会要求你重配服务。
