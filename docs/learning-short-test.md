# 英语收尾与记录短测

> 本轮已结束，三项反馈已齐。用户感觉基本合适；英文入口漏判已修，识别错误与口头总结、跨会话读取仍未通过真人验收。详见[反馈记录](learning-feedback-2026-11-01.md)。暂不重复测试，以下步骤保留供后续集中验证。

2026-11-01，预计 3–5 分钟。只体验本轮英语收尾，不用重复唤醒或红茶／绿茶测试。学习记录和虚构偏好都放在隔离目录；会使用已开通的云服务。

1. 刷新 [8767 测试页](http://127.0.0.1:8767/)，保持前台，点“开始聊天”。说“陪我练英语”，再说一句简单英文，例如 **I eat bread for breakfast.**，自然聊一两轮。不需要故意犯错。
2. 说“我不明白，请用中文解释一下”。观察它是否先中文解释、保持英语练习模式，以及问题是否适合你的水平。
3. 说 **“今天练到这里”**。应回日常模式并简短总结；若需要较久整理，应明确说明还在处理。留意是否把没聊过的内容说成学过，或把正确表达当错误。
4. 等页面“学习记录”显示已整理，再点“结束聊天”，重新点“开始聊天”。问“刚才的英语练习出现过什么词？”——应能依据记录回答；这不是对英语掌握程度的评价。
5. 可选：再次说“陪我练英语”，随便聊一句，直接点“结束聊天”。应关闭麦克风，后台保存，不突然开口总结。此时不必等待，不必为测试重新开始。

有异常只记大约时间、你说的话和实际表现，不用反复重试。若出现“这句话还没有识别完成”，确认自己说完后才可选择“我说完了”；不用刻意制造停顿或测试恢复。

完成后告诉我 **“测试结束”**。我会先核对日志，再询问话题难度、中文求助、总结准确性和等待感。未测项目保留为未测，不需要一次完成所有项目。
