1. 当前明确保存规则只兼容“不不不，我说的是……”这一类前缀；对本轮“不，请记住……”返回 false。需要区分口语更正与真正的“不要记住”，不能直接删除所有“不”。

4. 本地生成的确认问题与普通对话回复必须引用一致的有效状态；查询不能擅自把“喜欢”升级为“最喜欢”，也不能把待确认更正当最终事实。
